# Brand assets: provenance

These images are trademarks of their owners. passforge uses them only so a generated pass looks like the card it
stands for (nominative use). passforge is not affiliated with any of these companies.

**Takedown:** if you own one of these marks and want an image removed, open an issue or e-mail the maintainer; it
will be removed promptly, no questions asked.

Rules for this folder: no photos of anyone's personal card, nothing showing a card number, name, barcode or other
personal data. Metadata chunks (`tEXt`, `tIME`, `eXIf`) are stripped from committed PNGs.
